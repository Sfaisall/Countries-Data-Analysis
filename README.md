# Countries Data Analysis

## Objective
To analyze global country data using Python and Pandas.

## Dataset
Countries Dataset containing demographic, geographic and economic information.

## Tools
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Analysis Performed
- Dataset inspection
- Population analysis
- Country comparisons

## Key Findings
- China has Maximum Agricultural land
- Tuvalu has the lowest population.
- New Delhi is the capital of the highest population country.
- China has the Highest Female population in the World.
- Norway has highest Democratic Score.
